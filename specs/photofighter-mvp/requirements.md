# PhotoFighter MVP 要件定義

## 概要

ユーザーが自分の写真をアップロードすると、Amazon Bedrock（Nova Canvas）を使ってゲーム用アバターキャラクターを自動生成し、そのキャラクターを操作して可愛い敵キャラと1対1の格闘バトルを楽しめるWebブラウザゲーム。

## ユーザーストーリー

### US-1: アカウント管理
- ユーザーとして、メールアドレスとパスワードでアカウントを作成し、ログインできる

### US-2: キャラクター生成（キャラクリ）
- ユーザーとして、自分の写真をアップロードし、格闘ゲーム風のアバターキャラクターを生成できる
- 写真はサーバーのメモリ上で処理し、S3に永続保存しない（処理完了後即削除）
- 1ユーザーあたり月5回までの生成制限を設ける（コスト制御）

### US-3: 格闘バトル（1ステージ）
- ユーザーとして、自分のアバターキャラクターを操作して敵（オニ）と1対1で戦える
- PC: キーボード操作（矢印キー + Z/X/C）
- スマホ Chrome: 仮想パッド操作

### US-4: ゲーム結果
- ユーザーとして、バトル結果を確認し、再戦できる

## 非機能要件

- セキュリティ: 写真データは外部サービスに送信しない、WAF適用
- パフォーマンス: キャラ生成30秒以内、ゲーム60fps (PC) / 30fps+ (スマホ)
- コスト: 月額 $10 以下
- プライバシー: アップロード写真はメモリ上のみ、ディスク/S3保存禁止

## 制約事項

- バックエンド: Python 3.12 + FastAPI
- フロントエンド: React + Vite + TypeScript + Phaser 3
- インフラ: AWS (App Runner, DynamoDB, S3, Bedrock, CloudFront)
- IaC: AWS CDK (TypeScript)
- テスト: pytest (カバレッジ80%以上)
- コード整形: Ruff
